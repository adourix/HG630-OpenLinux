# OpenLinux V0.3 core services

Date: 2026-11-10

## Implemented

`openlinuxctl` remains a POSIX shell/BusyBox runtime component. It now provides:

- `status` and configuration validation;
- network interface discovery from `/proc/net/dev`, static/DHCP validation,
  and `network apply --dry-run`; explicit apply additionally requires
  `OPENLINUX_ALLOW_APPLY=1`;
- DHCP/DNS validation and generation of an OpenLinux-owned dnsmasq-compatible
  file, including optional static leases and local hosts;
- firewall backend detection (`nftables`, preserved vendor `iptables`, or
  unavailable) and proposed rule validation without flushing or applying rules;
- SSH binary/configuration status and validation, with SSH disabled by default;
- `/proc` uptime/load/memory/mount monitoring;
- bounded OpenLinux log rotation and status reporting.

The inventory verified `/bin/ip`, `/sbin/udhcpc`, `/bin/iptables`, `/bin/sshd`,
and vendor `dns`/`dhcps` binaries. No `dnsmasq` or `nft` binary was found.
OEM configuration files and daemons are not replaced.

## Tests and ARM execution

The userspace test module covers configuration errors, invalid interfaces, DHCP
generation, static leases/local hosts, firewall rules, SSH validation, fake
`/proc` monitoring, dry-run guarantees, and boot logging. The complete suite
passes **46/46** after the V0.3 changes.

The V0.3 staged RootFS was executed with `qemu-arm` and the preserved ARM
BusyBox. Verified outputs included all service statuses, network validation,
DHCP generation, `vendor-iptables` detection, SSH status, and dry-run command
handling. QEMU user mode does not provide a Linux kernel, router devices, MTD,
DSL, Wi-Fi, or hardware-boot evidence.

## Remaining blockers

Actual init-time service ordering, DHCP/DNS daemon operation, firewall rule
application, SSH exposure policy, vendor network device names, kernel SquashFS
BCJ support, kernel boot, OEM update acceptance, and hardware compatibility are
not validated. No service is enabled automatically and no physical MTD or router
was accessed.
